# herdr-goal-manager v0.1.0

Talk through a problem with Claude Code, Codex or Copilot in a Herdr tab, let
the agent in your original tab do the work, and keep the goal, evidence and
budget outside the conversation.

## Install

```sh
herdr plugin install nwiizo/herdr-goal-manager --ref v0.1.0
```

Or download `hgm-v0.1.0-<target>.tar.gz` for macOS or Linux (arm64, x86_64),
check it against `SHA256SUMS`, extract it, and run `herdr plugin link` on the
extracted folder. Bind `herdr-goal-manager.open` to a key (see the README).

## Highlights

- One manager per original tab, using the same agent as that tab; reopening
  switches to it.
- Loop contracts with enforced confirmation, budgets and word limits.
- Linked assignments, corrections, goal checks and interrupt delivery to a
  working Claude Code or Copilot.
- Event-based monitoring with a 10-second polling fallback: holds for dialogs,
  sign-in and limits, provider-error handling, settle checks, notifications, a
  Goal watch tab and sidebar state, and context handoff with restart in the
  same tab. A running watch continues in a redeployed build.
- Implementer and reviewer roles, one per name and tab.

## Limits

See the README's Limits and `docs/verification.md`. Interrupt delivery stays
off for Codex, whose native checks are pending. Copilot roles need a folder
Copilot already trusts, and Copilot managers need an explicitly chosen capable
model. No unattended reliability claim is made.
