# herdr-goal-manager v0.1.3

Stopping one goal now leaves its neighbors under supervision. Linked assignments
recheck task eligibility before delivery, and a restarted watch remembers a
provider continuation that may already have reached the worker. Cross-check
workers stop their own process groups. A legacy cross-check without an exit
record is marked unconfirmed.

Acceptance after a wait rechecks the work. Human-readable reports filter
terminal control characters while JSON retains the original text.

## Upgrade

Move any `hgm add --check` commands into the goal file's `checks` list and run
`hgm add --file PATH`. Use `hgm init --command-example` for a complete example.
Project prompt includes must resolve to files inside the workspace.

## Install

```sh
herdr plugin install nwiizo/herdr-goal-manager --ref v0.1.3
```

Prebuilt archives are available for macOS and Linux on arm64 and x86_64.
Verify the download against `SHA256SUMS`, extract it, and run `herdr plugin link`
on the extracted directory.

For a Cargo installation, run `cargo install herdr-goal-manager --version 0.1.3 --locked`,
then `hgm plugin-folder` and `herdr plugin link ~/.local/share/herdr-goal-manager/plugin`.
