# herdr-goal-manager v0.1.1

A fallback install from crates.io. Goal Manager itself is unchanged from v0.1.0.

## Install

```sh
herdr plugin install nwiizo/herdr-goal-manager --ref v0.1.1
```

Or download `hgm-v0.1.1-<target>.tar.gz` for macOS or Linux (arm64, x86_64),
check it against `SHA256SUMS`, extract it, and run `herdr plugin link` on the
extracted folder. If neither works for you, install from crates.io:

```sh
cargo install herdr-goal-manager --locked
hgm plugin-folder
herdr plugin link ~/.local/share/herdr-goal-manager/plugin
```

Bind `herdr-goal-manager.open` to a key (see the README).

## Changes

- `hgm plugin-folder` makes a Herdr plugin folder around an installed `hgm`:
  the plugin manifest and a link to the binary, so upgrading the binary
  upgrades the plugin. A folder holding another plugin or an hgm build is left
  alone.
- The crate is published on crates.io.

## Limits

As in v0.1.0: see the README's Limits and `docs/verification.md`. Interrupt
delivery stays off for Codex, whose native checks are pending.
